# پلتفرم امیرعلی | فروشگاه + آموزشگاه رباتیک

نسخه‌ی پایه Full-Stack برای اجرای سریع:
- Frontend: React + Vite
- Backend: Express
- SQLite برای توسعه سریع (قابل تعویض با PostgreSQL)
- احراز هویت با JWT در HttpOnly Cookie
- نقش admin/user
- فروش محصولات، دوره‌ها و فایل‌های دیجیتال
- LMS، تاریخ بازشدن جلسات، کلاس آنلاین و تکلیف
- سفارش، آدرس ارسال، آپلود فیش و صف مدیریت
- اتصال کیت‌های رباتیک به دوره‌ها

## اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:5173`

## متغیرهای محیطی
فایل `.env.example` را کپی کنید و مقادیر واقعی را در `.env` یا Secrets محیط اجرا قرار دهید. اطلاعات ورود مدیر و اطلاعات پرداخت را در مخزن عمومی ذخیره نکنید.

## نکته پرداخت
تأیید پرداخت باید قبل از تحویل محصول با بررسی بانکی/دستی انجام شود. OCR در نسخه نهایی فقط ابزار کمکی است و نباید به‌تنهایی مبنای تأیید قطعی پرداخت باشد.

> این مخزن نسخه پایه پروژه است و بخش‌هایی مانند سفارش‌اقلام، فعال‌سازی خودکار دوره پس از تأیید و پخش واقعی ویدئو باید در نسخه production تکمیل شوند.
